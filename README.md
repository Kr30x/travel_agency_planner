# 🏨 Планировщик размещения гостей отеля

Стабильное веб-приложение для управления размещением гостей с генерацией PDF-отчётов + списки для ГАИ/транспорта.

## 🚀 Возможности

### 🏨 Размещение в отеле:
- ✅ Загрузка данных гостей из Excel файлов
- ✅ Drag & Drop интерфейс для распределения гостей по номерам
- ✅ Поддержка разных типов номеров (одноместные, двухместные, люксы и т.д.)
- ✅ Генерация профессиональных PDF-отчётов

### 🚌 Списки для ГАИ/Транспорта:
- ✅ Быстрое создание списков пассажиров
- ✅ Добавление целых классов одним кликом
- ✅ Указание маршрута поездки
- ✅ PDF без паспортов, с контактами родителей

### 🎯 Общее:
- ✅ Система проектов - работайте над несколькими распределениями
- ✅ Фильтры по классу и статусу (ученик/учитель)
- ✅ Поиск по ФИО
- ✅ Автосохранение прогресса
- ✅ Предпросмотр PDF
- ✅ Современный минималистичный интерфейс

## 📋 Требования

- Python 3.8+
- pip

## 🔧 Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте браузер и перейдите по адресу: `http://localhost:5001`

## 📊 Формат Excel файла

Excel файл должен содержать следующие колонки:

| ФИО | Дата рождения | Паспорт | Контакт родителя | Класс | Статус |
|-----|---------------|---------|------------------|-------|--------|
| Иванов Алексей Петрович | 15.03.2009 | 4512 234567 | +7 (916) 123-45-67 | 9А | Ученик |

В проекте есть файл `sample_guests.xlsx` с примером данных.

## 🎯 Как использовать

### Создание проекта:
1. Нажмите **"+ Новый проект"**
2. Выберите тип: **🏨 Размещение** или **🚌 Список для ГАИ**
3. Введите название

### Для размещения в отеле:
1. **Загрузите Excel файл** с данными участников
2. **Добавьте номера** отеля
3. **Перетащите гостей** в нужные номера (Drag & Drop)
4. **Создайте PDF** отчёт

### Для списка ГАИ:
1. **Загрузите Excel файл** с данными участников
2. **Укажите маршрут** (например: "Москва → Санкт-Петербург")
3. **Перетащите участников** в список или добавьте целый класс
4. **Создайте PDF** список для ГАИ
